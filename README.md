# solatla-data

Cermin Taqwim KHEU (Brunei) untuk app Solatla.

- `kheu/bn_<tahun>.json`: waktu solat asas Brunei-Muara & Temburong, diekstrak
  daripada Taqwim rasmi Kementerian Hal Ehwal Ugama Negara Brunei Darussalam
  (https://www.mora.gov.bn). Tutong +1 minit, Belait +3 minit dikira oleh app.
- Format: `{"year":2026,"days":[["2026-01-01","05:05","06:28","12:25","15:46","18:19","19:34"], ...]}`
  (tarikh, subuh, syuruk, zohor, asar, maghrib, isyak; jam 24).

Hak cipta data waktu solat milik penerbit asal.
